# SIC.

**Nothing new under the sun.**

SIC. is a semantic search project for ideas found across literature, philosophy, religion, mythology and historical texts.

The goal is simple: describe an idea in natural language and find passages that express a similar thought — with the author, work, location, original text, translation, context and verifiable source.

## Core principle

**No fabricated quotations.** Every result must be traceable to a real text. If no reliable match is found, SIC. should say so.

## Current status

This repository currently contains the first responsive website prototype. The search interface is visual only; the verified corpus and semantic retrieval engine have not been connected yet.

## Project principles

- Prefer primary texts and trustworthy editions.
- Track translation and edition rights separately from the original work.
- Keep quotations distinct from interpretation.
- Make source links and surrounding context visible.
- Never present an unverified match as a quotation.

## Run locally

Open `index.html` in a modern browser. No build step is required for this first prototype.

## Roadmap

1. Build the responsive interface.
2. Define a structured, source-traceable text corpus.
3. Add semantic retrieval over the corpus.
4. Add passage verification, context and source links.
5. Expand the collection and language support.
